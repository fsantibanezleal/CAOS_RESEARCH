# EXP-022 preflight - defining ideal of the conductor fiber cone

Date: 2026-08-17.

## Decision-bearing question

For every `p>=4`, let `C_p=F(T_p)` be the conductor special fiber proved Cohen--Macaulay in
EXP-021, let `q=24p`, and let

```text
S_p=k[X_a : a in Min(v(T_p))],
phi_p:S_p -> C_p,  X_a |-> class(t^a).
```

There are `10p` variables, one of which is `X_q`; `X_q` is a degree-one parameter. The next
structural problem is to determine `J_p=ker(phi_p)` uniformly. The invariant-first question is
whether the degree-two value congruence already generates `J_p`.

For a degree-`n` monomial `M=product X_(a_i)`, its image is governed exactly by the value sum
`sigma(M)=sum a_i`:

- `M` maps to zero precisely when `sigma(M)` belongs to `v(m_pT_p^n)`;
- two nonzero monomials have the same image precisely when their value sums agree.

Thus every homogeneous kernel component is a direct sum of zero-monomial classes and equality
relations within fibers of `sigma`. This converts defining-equation discovery into exact finite
congruence and connectivity, without numerical linear algebra or an imported verifier.

## Candidate theorem and distinguishing invariant

Let `K_p` be the ideal generated by the complete degree-two kernel of `phi_p`: every quadratic
monomial with zero image and, inside every nonzero equal-sum fiber, a spanning tree of binomial
differences. Since there is no degree-one kernel,

```text
beta_(1,2)(C_p)=dim_k (J_p)_2
  = binom(10p+1,2)-dim_k(C_p)_2
  = 50p^2-17p.
```

The strongest candidate is `K_p=J_p` for all `p>=4`. The distinguishing invariant is not a
generic Groebner computation: in each degree, multiply the known quadratic relations by all
variables and form the induced congruence graph on monomials. Quadratic generation holds in that
degree exactly when the graph connects every actual equal-sum fiber and connects every actual
zero monomial to the zero node.

## Alternatives and redirect criteria

- If the `p=4`, degree-three gate fails, quadratic generation is refuted immediately. Preserve the
  first disconnected fiber and compute the exact minimal cubic obstruction before proposing a
  higher-degree theorem.
- If degrees three and four pass but degree five fails, preserve the first degree-five obstruction;
  the source theorem makes degree five the final possible new-generator degree.
- If the smoke gate passes through degree five, test several parameters and derive interval-level
  connectivity lemmas. Finite agreement will not prove the parametric statement.
- A complete Rees ideal remains out of scope: it has a larger proof surface and is not required to
  decide `J_p`.
- A mere listing of the source theorem's nonminimal generators is a reproducibility fallback, not
  the target result.

## Validation and compute discipline

Route A enumerates symmetric monomials, exact value sums, actual zero/equality fibers, and the
relations induced from the preceding degree. Route B independently reconstructs the Artinian
basis blocks and expected quotient dimensions from EXP-021's closed formulas. The mandatory
smoke parameter is `p=4`; it proceeds degree by degree and stops on the first mismatch.

The smoke budget is five CPU minutes and 2 GiB working memory. Any broader campaign requires a
successful smoke run, checkpointed per-degree summaries, and a separate five-minute budget. Exact
integer arithmetic only; no randomness. Budget exhaustion is `INCONCLUSIVE`. A finite pass is
implementation evidence only; a theorem for all `p` requires symbolic interval/congruence proof.

## Exploration moment

The standard presentation problem initially looks like elimination in `10p` variables. Passing
to the Artinian reduction exposes a different structure: it is a finite commutative automaton in
which states are the known offset blocks `D_0,...,D_4` and multiplication adds a degree-one
offset or falls into zero. The defining-ideal problem is therefore a confluence/connectivity
problem for that automaton. This lens can prove quadraticity or produce a smallest obstruction
without computing a large Groebner basis.
