## Deviations from the brief and the hypothesis, and notes

- The Singular script lists a zero vector as a generator of the last syzygy module when the module has no third syzygy (seen on the infinite modules of C2 in characteristic 2); the script skips zero vectors, so tables count nonzero generators only. The first run of C2 before this fix printed the artifact (3, -1000000, 1); it is not in results.json.
- C3 also lists e = 2 (a control equal to C1); the hypothesis range is e = 3..6.
- C4 over QQ uses the integer representatives in [0, 32003) of the GF(32003) draws as the lifted matrix.
- C5: I2 was run on up to 3 table hits per field, not on every finite pair; I1 tables are computed for every finite pair. For infinite quotients only the Hilbert function through degree 14 exists.
- C6: for the 2 x 3 quadric cokernels the table of M is symmetric under the reversal, so the reversal check is a weaker test there; the 3 x 5 cokernels have non-palindromic Hilbert functions (3,1,2) and a non-symmetric table, so M and M* are not isomorphic up to shift.
- Coefficients over QQ are `fractions.Fraction`; GF(p^k) uses a polynomial representation with a brute-force verified irreducible modulus (`code/uhlib/fields.py`), and the same modulus is passed to Singular as `minpoly`.
