This directory contains declared, resumable computational work. A complete
local inequality is established only after every shard and the independent
audit finish. Hypotheses, preflight proofs and checkpoints are not a
completed proportion theorem.

Use the repository Python environment with `python-flint==0.9.0`, SymPy
and pytest. From the repository root:

```text
python -m pytest -q tests/test_riemann_local_replay.py tests/test_riemann_certified_quadratic.py
python problems/number-theory/riemann-hypothesis/experiments/EXP-019-nine-point-local-replay/run.py --stage full --workers 24 --output-dir E:/_Datos/caos-research/riemann-hypothesis/exp019-local-replay-20261003

```

no shard. Completed states still undergo deterministic initial-cover checks.

outside Git. The frozen source, exact packet, small receipts and code are
tracked. At completion their heavy-file manifest must bind every retained
artifact.
