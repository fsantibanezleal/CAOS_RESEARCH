## Source ready for the next version

The source in this folder is v0.05 (dated 14 November 2026) and is not published. Its title is
"Exact minimum size on the first interior shell of the Bougard-Joret problem, with the extremal graphs at independence
numbers two and k-1", re-derived from the shell theorem (the value on the whole shell), the cycle-complement theorem
(the extremizers at independence number two) and the tree theorem (the extremizers at independence number k-1);
`zenodo.json` carries the same title, the abstract as description and the version notes. The folder name `tree-strip`
no longer matches the scope of the paper and is kept only because records link to it.
The statements and proofs of the three theorems are unchanged from v0.04. New in v0.05: a related-work section; a
section of algorithms with costs (leaf augmentation of trees, vertex-split flow connectivity, independence number by
recursion, the labeled residual enumeration with permutation reuse, the shell construction); a results section with the
75 shell constructions, the negative controls, the labeled residual enumeration, the second-line shortfall and an ablation;
tables and figures generated by `make_tables.py` from the saved certificates, and `zenodo.json` rewritten by
`make_zenodo_json.py`; the shell parameter `d = k - a` is renamed `g`, and the proof states the requirement
`m >= 2r + 4` of the cyclic-gap lemma. The release and the review are separate steps.
