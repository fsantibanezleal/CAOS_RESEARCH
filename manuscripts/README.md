folder holds `main.tex` and its built `main.pdf`, which is the file published on Zenodo
for the version listed below. Relocated from three root-level folders on 2026-07-23; git
history is preserved through the rename.

The web app links each problem's manuscripts directly from its problem page.

A concept DOI always resolves to the latest version of its paper. Versions are frozen once
published; a revision is published as a new version of the same record, and its changes are
listed in that version's notes on Zenodo. The manuscripts follow the scientific-voice rules in
`methodology/05-writing-standards.md` and `methodology/09-manuscripts-and-publication.md`,
checked by `scripts/check_manuscript_voice.py`.
